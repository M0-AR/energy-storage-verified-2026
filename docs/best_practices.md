# docs — best practices (2026-27 field guide)

See README §3. Checklist before procurement:
- [ ] Usable kWh defined (SOC, T, PCS, aux, reserve)?
- [ ] AC vs DC efficiency boundary stated?
- [ ] Same duty/thermal/control for all bids?
- [ ] Six PIs tracked (cap, P-tol, Rint, RTE, response, standby)?
- [ ] Degradation by throughput+calendar+T, not single %?
- [ ] Aux load metered in heat + standby?
- [ ] Fault logs + thermal spread reviewed, not just certs?
- [ ] LCOS swept over RTE + FLH + fees; capacity value for rare-use LDES?
- [ ] Warranty exclusions (T, cycling, SW) matched to KPIs?
- [ ] Provenance logged (URL, sha, UTC) for every external number?
